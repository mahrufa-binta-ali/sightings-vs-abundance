\# Data



The raw and processed datasets used in this project are not redistributed in this repository.



The analysis combines:



\- Wood Thrush community-science occurrence records for New York during the 2023 breeding season

\- Modeled Wood Thrush relative-abundance data

\- New York geographic boundary data



Raw data should be obtained directly from their original providers and used according to the applicable licenses and terms.



The scripts in `src/` document the processing workflow used to generate the derived grid-level analysis dataset.
